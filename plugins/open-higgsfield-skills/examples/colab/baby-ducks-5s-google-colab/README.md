# baby-ducks-5s-google-colab

Bundle generated by `google-colab-runner` for the video-director manifest `baby-ducks-5s`.

## Use it
1. Open `baby-ducks-5s.ipynb` in Google Colab (File > Upload notebook). Pick a GPU runtime.
2. Add your own Hugging Face token as the Google Colab secret `HF_TOKEN` if any model repo is gated.
3. If the bundle has assets, upload `baby-ducks-5s-google-colab-assets.zip` to `/content` or MyDrive.
4. Run cells 1-10. Cell 7 starts a watchdog that releases the runtime at the session cap or when idle.
5. Bring `baby-ducks-5s-google-colab-outputs.zip` home and run `colab.py ingest <manifest> <zip>`, then judge and continue with `direct.py run`.

Or run `python runner.py --url <ComfyUI URL>` against any ComfyUI that has the nodes and models.
